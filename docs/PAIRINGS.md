# Pairings
Find > Pairings supports cigar-to-drink and drink-to-cigar suggestions. Select collection only, new suggestions only, or both. Saved items appear as name suggestions. Optional flavor notes refine the request.

Each search consumes one AI request under the existing plan and bonus-credit system. The client shares the starting item and up to 80 opposite-category in-stock records with Anthropic, bounded by the request text limit. Photos, prices, account emails and other collection sections are omitted. Existing AI consent is required. Extra profiles may be omitted to stay within the text limit.

Up to three matches per group are displayed. Owned match names are replaced server-side with the submitted inventory names, indices are checked, and duplicates are removed. The client rechecks availability before rendering. New product suggestions are AI generated, not a verified catalog or availability guarantee. No purchase links are provided. Journal actions create an editable unsaved draft, not an inventory transaction or a consumption record.

Native and web builds include the same disclosed feature. Review against current store tobacco policies remains necessary before submission. Neither age gating nor existing competitors guarantees store approval.
