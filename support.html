Torcida Beta Help

Move your existing collection into the iPhone app

  1. Open the existing Torcida website in the browser where your collection is saved.
  2. Open Settings → Download backup and save the JSON file to Files. Keep the original.
  3. Open the installed Torcida beta, then Settings → Restore backup. Choose the JSON file.
  4. Review the preview. The app first asks you to save a backup of the collection currently in the app, then restores the selected file.
  5. Check cigar and journal counts, photos, and ratings. Keep both backup files until you have verified the transfer.

Safari and the installed app have separate storage. Nothing transfers automatically. Restore replaces the app’s current collection; it does not merge collections.

AI and camera

You can decline AI sharing and still maintain your collection manually. AI lookup requires internet access and may reach a daily usage limit. Camera access is optional; select a photo or enter a name instead. If access was denied, review Torcida’s permissions in iPhone Settings.

Sharing and saving

In the iPhone beta, use the system share sheet’s Save to Files action to keep JSON backups or PNG tasting cards. Preview a tasting card before sharing; location and personal notes are off by default.

Report a problem

In TestFlight, select Torcida → Send Beta Feedback. Include your device model, iOS version, the steps you took, and what happened. Use sample data and redact private notes/photos from screenshots. Please do not send backups containing private data unless you have explicitly agreed to share them.

The app owner must add a monitored public support contact before App Store submission. See the submission checklist.
