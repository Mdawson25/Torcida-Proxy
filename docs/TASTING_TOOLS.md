# Personal tasting tools and private groups
Journal > Explain my taste uses rated journal entries and a fixed flavor vocabulary. Each pattern shows the sample count and average rating. Fewer than three supporting entries are marked Early guess. These are observations from recorded text, not scientific measurements or causal preference claims. No AI request or external transfer is needed.

Humidor > Humidor timeline shows purchase date, elapsed calendar days and repeated journal notes. Missing dates stay unknown. Purchase time does not prove production age or storage quality. Journal records match by source record ID or normalized brand/name. Different sizes with the same recorded name may match. Purchase dates can be edited and synced.

Journal > Side-by-side tasting hides entered item names after the comparison begins. Scores are not randomized or professionally blinded. Both samples need a 1–5 rating. Reveal and save persists an independent comparison record before showing names. Comparisons do not count as consumed cigars or reduce stock. Drafts are held only in memory. Saved comparisons use optional collection.tastings, synchronize by record ID, and are retained in JSON backups and imports. CSV export continues to cover inventory and journal records, not comparison data. Use JSON for a full backup.

Journal > Private tasting groups requires sign-in and an internet connection. Run database/005_tasting_groups.sql after migration 004. Members join with a private 48-character invite code. Hosts can rotate codes, create sessions, reveal results and delete their groups. Members can leave. Groups allow up to 50 members, up to 100 sessions each, and up to 20 memberships per account. Join attempts are limited to five per minute. New codes do not remove existing members.

Before reveal, every member including the host sees only their own score and notes. Hosts may reveal at any time. After reveal all members see submitted display names, session ratings and notes, and edits are locked. A session has a lineup and one overall rating plus notes per member. Group snapshots can be downloaded separately. Member emails are not returned to other members. Group tables use RLS and deny direct anonymous/authenticated access. Only the authenticated server derives actor identity and invokes the restricted RPC. Account deletion cascades owned groups and personal submissions. Leaving a group removes that member's submissions. No invitations or messages are sent automatically.

Run npm test and npm run build. Live Supabase migration, two-account group testing and physical-device layout verification remain owner checks. All web and native builds disclose the same feature set.
